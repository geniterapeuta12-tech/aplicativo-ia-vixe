# CoderBuilder 2.4.0-alpha.1

Status: active development / test build.

Included in this version:
- project versions are now first-class: every project starts with Version 1;
- create, open, duplicate, publish and delete versions;
- published version is clearly separated from the version currently being edited;
- published version cannot be deleted until another version is published;
- the last opened project/version is restored from local storage;
- each version can contain multiple files;
- default web project supports index.html, style.css and script.js;
- HTML, CSS and JavaScript are combined automatically for live preview/export;
- JSON, Markdown, TXT, Python, TypeScript, JSX/TSX, XML and YAML can be edited and stored;
- Python and other non-browser languages are not executed in this version;
- preview controls remain available: zoom, auto, portrait and landscape;
- Android and Windows share the same interface source;
- data remains local/offline in 2.4 alpha; Supabase integration is intentionally not enabled yet;
- CoderBuilder 2.3 remains preserved on its own branch.
