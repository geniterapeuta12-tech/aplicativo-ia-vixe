# CoderBuilder 2.5.0-alpha.1

Status: active development / cloud test build.

Included in this version:
- keeps the 2.4 project/version/multi-file editor model;
- connects the app to the dedicated CoderBuilder Supabase project;
- email authentication is handled by Supabase Edge Functions;
- cloud upload/download for projects, versions and files;
- local storage remains available as a fallback/offline copy;
- Android and Windows use the same CoderBuilder cloud interface;
- published/current version relationships are synchronized;
- Row Level Security remains enabled in the database;
- CoderBuilder 2.4 remains preserved on its own branch.
